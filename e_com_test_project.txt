# QA E-commerce Testing Project

## Overview
This project simulates a QA testing process for a basic e-commerce system including login, product browsing, cart management, and checkout functionality.

The goal of this project is to demonstrate practical QA skills through:
- Manual test case design
- Bug reporting
- Basic automation (smoke testing)

The project is written from a **QA perspective**, not a development perspective.

---

## System Under Test (SUT)
The simulated e-commerce system includes:

- User Login
- Product Listing
- Shopping Cart
- Checkout Process

This system is similar in structure to real-world platforms such as large e-commerce applications like Amazon or eBay.

## Testing Coverage

### Manual Testing
- Login functionality
- Product listing and search
- Cart operations (add, remove, update)
- Checkout process validation

### Bug Reporting
- Structured bug report example for login module
- Includes severity, priority, steps, and expected vs actual results

### Automation
- Basic smoke tests using Python
- Valid and invalid login scenarios
- Simple assertion-based testing

## QA Skills Demonstrated

- Test case design (positive & negative scenarios)
- Edge case thinking
- Functional testing
- Basic security awareness (SQL injection attempt coverage)
- Bug reporting and documentation
- Understanding of end-to-end system flow
- Basic test automation (smoke testing)
