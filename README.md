# QA E-commerce Testing Project

## Overview
This project simulates a real-world QA testing process for an e-commerce system, covering key functionalities such as login, product browsing, cart management, and checkout.

The focus of this project is on **manual QA testing skills**, supported by basic automation using Python.

---

## Project Goals
- Demonstrate QA thinking and test design skills
- Cover end-to-end e-commerce workflow
- Practice structured bug reporting
- Introduce basic automation (smoke testing)

---

## System Under Test
The simulated e-commerce flow includes:

- User Login
- Product Listing & Search
- Shopping Cart
- Checkout Process

---

## Testing Types
- Manual testing (main focus)
- Functional testing
- Negative testing
- Edge case testing
- Basic automation (smoke tests)

---

## Project Structure
- `manual_testing/` → Test cases for all modules
- `bug_reports/` → Example bug reports
- `automation/` → Basic Python smoke tests

---

## Tools Used
- Python (basic automation)
- Markdown (test documentation)
- GitHub (version control)

---

## Key Focus
This project is designed from a **QA perspective**, focusing on:
- Real-world testing workflows
- Clear and structured documentation
- Practical QA mindset over coding complexity
